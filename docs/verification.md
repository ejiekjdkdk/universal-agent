## 本机离线耗时

每个场景通过回环 HTTP 顺序提交 20 次样例，均执行 1 次业务工具。P50 与 P95 按样本排序取最近秩。以下数值只描述本机这次运行。

| 场景 | HTTP P50 / P95 | 工具 P50 / P95 |
| --- | --- | --- |
| 资料问答 | 38.4 / 47.9 ms | 16 / 23 ms |
| 文本分析 | 32.4 / 38.4 ms | 11 / 13 ms |

要测试自己的模型，配置 README 所列环境变量后选择「模型模式」，询问示例资料中的事实。检查 Trace 中的模型轮次、工具执行、权限结果，并展开回答下方的证据核对原文。
